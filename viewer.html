How to read this board

  • Each column is a branch; the colored title card is the branch name. The green one is the main line.
  • Each card is a commit (a saved snapshot of the code). Newer is higher, older is lower.
  • A line joins a commit to the one it was built on.
  • dashed line: where a branch split off from main.
  • solid line into main: a merge, the branch's work landing on main.
  • Dashed card border: committed here but not pushed to the remote yet.
  • Click any card or branch title for a plain-English explanation.
