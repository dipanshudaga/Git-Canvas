How to read this board

  • Each column is a branch. Its colored title sits right above its newest commit. Green is the main branch.
  • Each card is a commit: a saved snapshot of the code. Newer is higher.
  • A white card with a colored border above a branch is its pull request.
  • dashed line: where a branch split off main.
  • solid line into main: a merge.
  • Drag a card to move it. Drag a branch title to change the order of the columns. Tidy up puts everything back.
  • Click anything for a plain explanation and the exact Git commands.
  • Hover the icon next to a word to learn what it means.
