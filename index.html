How to read this board

  • Each column is a branch. Its colored title sits right above its newest commit. Green is the main line.
  • Each card is a commit: a saved snapshot of the code. Newer is higher.
  • A white card with a colored border above a branch is its pull request.
  • dashed line: where a branch split off main.
  • solid line into main: a merge.
  • Drag any card, or a branch title to move the whole column. Tidy up puts everything back.
  • Click anything for a plain-English explanation and the exact Git commands.
